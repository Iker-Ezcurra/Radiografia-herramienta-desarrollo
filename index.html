Visual studio code

Visual Studio Code (también conocido como VS Code) es un editor de código fuente gratuito y multiplataforma desarrollado por Microsoft

Las ventajas de usar visual son: Eficiencia y agilidad en la programación, Amplia compatibilidad con lenguajes y frameworks, Potentes herramientas de depuración y pruebas, Integración nativa con Git y control de versiones, Personalización y extensibilidad para adaptarse a tus necesidades
